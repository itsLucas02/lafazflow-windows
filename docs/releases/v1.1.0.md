# LafazFlow v1.1.0 — Persistent Whisper Engine

**Date:** 14/08/2026 (Asia/Kuala_Lumpur)
**Tag (proposed):** `v1.1.0`

## Highlights

- **Persistent Whisper engine.** LafazFlow now runs a crash-isolated background worker that loads your selected model once at launch and keeps it ready. Warm dictations no longer pay the repeated model-loading cost of a one-shot CLI.
- **Faster warm dictation.** On the owner's tested setup, measured warm P95 latency dropped by approximately **71%** versus the previous one-shot CLI build. This measurement is specific to that machine and configuration — see *Performance* below.
- **Missing-ending-word protection.** The recording is fully drained and the WAV finalized before transcription, so the last words you say are no longer lost.
- **Crash isolation and automatic recovery.** A native/CUDA failure can only take down the worker, never LafazFlow. The app restarts the engine, retries safely, and falls back to the identical-settings CLI compatibility path when needed.
- **Live-preview priority.** Final dictation always preempts live preview work, so preview never delays your paste.
- **Performance-health monitoring.** Sustained slowdowns are detected against your machine's own baseline and trigger a bounded, logged recovery.
- **Improved Diagnostics.** Plain-language engine status, active backend, cold/warm latency summaries, recovery history, and character-stage diagnostics.
- **Prompt-leak protections.** The vocabulary prompt can no longer leak into the live preview or pasted output.
- **Package provenance manifest.** Every release embeds `LafazFlow-artifact-manifest.json`, recording the shipped binary hashes and exact whisper.cpp revisions.

## Performance

Performance varies by hardware, model, and workload. The approximate **71% lower warm P95** figure was measured on the owner's **NVIDIA RTX 4070 laptop**, using the **Quality profile with CUDA, `ggml-large-v3-turbo-q5_0.bin`, Silero VAD, English, and 16 threads**, on retained real-speech fixtures. Do not expect the same improvement on every computer; CPU-only machines and smaller models will differ. A clean-machine CPU package is verified independently.

## Installation and upgrade from v1.0.0

1. Download either `LafazFlow-1.1.0-win-x64-portable.zip` or `LafazFlow-1.1.0-setup.exe` from the release page.
2. **Portable ZIP:** extract the folder, then double-click `LafazFlow.Windows.exe`.
3. **Installer:** run the setup file and follow the prompts. You can install over a v1.0.0 installation; your settings and models are kept.
4. The standard public package works on CPU out of the box. Whisper models are downloaded separately from **Settings > Models**.
5. On first launch, allow microphone access and follow the first-run setup.

## Known limitations

- **Unsigned application.** The app is currently unsigned; Windows SmartScreen may show "Windows protected your PC". Click *More info* then *Run anyway*.
- **Models downloaded separately.** Whisper model files are not bundled; download them from **Settings > Models** (or import a local `.bin`).
- **CUDA is optional.** The Quality/CUDA profile requires a compatible NVIDIA GPU and a CUDA-enabled worker/CLI. Without it, LafazFlow uses the CPU path or the CUDA CLI compatibility path — it never silently downgrades CUDA settings.
- **Hardware-dependent behaviors.** Physical microphone switching and Windows sleep/wake depend on the machine's hardware and drivers; automated audio-fixture tests cover the engine paths, and live microphone verification is performed on the owner's machine.

## Privacy

All transcription is local and offline. No cloud transcription, no account, and no upload of your recordings. Recordings and logs are retained only when you enable *Keep recordings for diagnostics* in **Settings > Diagnostics**.
